# geological_plane_mobile
Interactive application specifically designed for mobile devices that allows students and professors to visualize in real-time the relationship between strike and dip parameters with their vector representations and stereographic projections.

**Main Features**

The application is completely self-contained and runs on any smartphone or modern browser without requiring installation or internet connection once loaded. Spanish (plano_geologico_movil.html) and English (geological_plane_mobile.html) versions 
are provided.
It consists of three interactive modules:

**1. Vectors Module**
Displays in real-time:
• Normal vector (perpendicular to the plane) - The most fundamental representation
• Strike vector (horizontal, along the strike line)
• Dip vector (direction of maximum slope within the plane)
• Calculated parameters: dip direction, pole trend, pole plunge

**2. Stereographic Projection**
Simultaneously visualizes:
• Great circle (geological plane trace)
• Pole to plane (projection of the normal vector)
• Reference circles for plunge
• Clearly marked cardinal directions

**3. Interactive 3D Visualization**
Allows:
• Touch rotation of the complete scene
• Geological plane visualization with realistic shading
• Horizontal reference plane for comparison
• All relevant vectors in color code
• Cartesian reference axes (East, North, Up)

# plano_geologico_movil
Aplicación interactiva diseñada específicamente para dispositivos móviles que permite a estudiantes y profesores visualizar en tiempo real la relación entre los parámetros de rumbo y buzamiento con sus representaciones vectoriales y proyecciones estereográficas.

**Características Principales**
La aplicación es completamente autónoma y funciona en cualquier smartphone o navegador moderno sin requerir instalación ni conexión a internet una vez cargada. Se proporcionan versiones en español (plano_geologico_movil.html) e inglés (geological_plane_mobile.html). Consta de tres módulos interactivos:

**1. Módulo de Vectores**
Muestra en tiempo real:
Vector normal: (perpendicular al plano) - La representación más fundamental.
Vector de rumbo: (horizontal, a lo largo de la línea de rumbo).
Vector de buzamiento: (dirección de máxima pendiente dentro del plano).
Parámetros calculados: dirección de buzamiento (dip direction), dirección de inclinación del polo (pole trend) e inclinación del polo (pole plunge).

**2. Proyección Estereográfica**
Visualiza de forma simultánea:
Círculo máximo: (traza del plano geológico).
Polo del plano: (proyección del vector normal).
Círculos de referencia para la inclinación (plunge).
Puntos cardinales claramente marcados.

**3. Visualización 3D Interactiva**
Permite:
Rotación táctil de la escena completa.
Visualización del plano geológico con sombreado realista.
Plano horizontal de referencia para comparación.
Todos los vectores relevantes mediante código de colores.
Ejes de referencia cartesianos (Este, Norte, Arriba).
